# Word Cloud Exercise

A JavaScript exercise that builds a word cloud from a paragraph of text, plus small practice files on callbacks, the spread operator and timers.

## Files

- `index.html`, `cloud.css`, `cloud .js`: the word cloud page
- `callback.js`, `spread.js`, `timer.htm`: smaller practice exercises

## How to run

Open `index.html` in a web browser. No build step is needed.
